# Glosario de términos

| Inglés | Español sugerido | Notas |
| --- | --- | --- |
| Calendar | Calendario | Mantener mayúsculas solo en títulos |
| Task | Tarea | Plural: Tareas |
| Focus Mode | Modo enfoque | Evitar traducir como “Modo de foco” |
| Project | Proyecto | — |
| Auto-schedule | Auto-programar | Usar “auto-programar” en verbos y “auto-programación” como sustantivo |
| Workspace | Espacio de trabajo | Confirmar con diseño en caso de ambigüedad |
| Provider | Proveedor | — |
| Sync | Sincronizar | Sustantivo: Sincronización |
| Waitlist | Lista de espera | — |
| Lifetime Access | Acceso de por vida | Mantener capitalización en títulos |
| Settings | Configuración | Plural no necesario |
| Notification | Notificación | — |
| Reminder | Recordatorio | — |
| Schedule | Programar | — |
| Sign In | Iniciar sesión | “Inicia sesión” en mensajes |
| Sign Up | Crear cuenta | Evitar “Regístrate” para consistencia |
| Reset Password | Restablecer contraseña | — |
| Email | Correo electrónico | Abreviar a “correo” cuando el contexto lo permita |
